# Coding at the Speed of AI: Who’s Watching the Dependencies?

AI coding assistants have accelerated how we write code and pull in dependencies, but review and scrutiny haven't kept pace. This talk examines the tension between AI-driven velocity and the accountability required to ship secure software. We will discuss practical ways to rebuild review discipline and learn to protect the entire software ecosystem rather than just evaluating individual packages. Join this session to gain a more sustainable, confident relationship with the code you ship, even when using AI tools daily.
